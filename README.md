# 🎳 Let's Go Bowling

A real brief look at Go. Some slides, then we write a bowling kata together.

## Setup

- [just](https://github.com/casey/just)
- Go 1.21+
- `go install gotest.tools/gotestsum@latest`
- Node, then `cd presentation && npm install`

## Go

```sh
just present     # slides
just test-watch  # tests, re-run on save
```

That's it. Enough READMEs.
